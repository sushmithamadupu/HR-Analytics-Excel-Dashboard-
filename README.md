**HR Analytics Dashboard – Excel**

**Project Overview**

This project focuses on analyzing employee attrition and workforce demographics using Microsoft Excel. The dashboard provides insights into employee turnover, department-wise attrition, job satisfaction, demographics, and workforce trends.

**Tools & Techniques**

*Microsoft Excel*

*Pivot Tables*

*Pivot Charts*

*Interactive Slicers*

*Data Analysis*

*Dashboard Design*

**Key Performance Indicators (KPIs)**

*Total Employees*

*Attrition Count*

*Attrition Rate (%)*

*Average Age*

*Average Monthly Income*

*Average Tenure*

**Dashboard Visualizations**

*Department-wise Attrition Distribution*

*Age Group-wise Attrition Rate*

*Employee Count by Job Role and Attrition Status*

*Gender-wise Employee Attrition Distribution*

*Overtime vs Employee Attrition*

*Employee Count by Tenure and Attrition Status*

**Interactive Features**

The dashboard includes interactive Excel slicers to filter and explore employee attrition across:

*Attrition Status*

*Job Satisfaction*

*Business Travel*

*Department*

*Gender*

**Key Objectives**

*Analyze employee attrition patterns*

*Identify departments and job roles with higher employee turnover.*

*Understand attrition across different age groups and genders.*

*Explore the relationship between overtime and employee attrition.*

*Analyze workforce distribution by employee tenure.*

**Conclusion**

This dashboard demonstrates the use of Excel Pivot Tables, Pivot Charts, and interactive slicers to transform workforce data into meaningful HR insights and support data-driven decision-making.
